{{- if eq .Values.svc.type "NodePort" }}
Access demodude via the following commands:
    echo "$(kubectl get nodes -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')"
    echo "$(kubectl get service -n {{ .Release.Namespace }} {{ .Values.svc.name }} -o jsonpath='{.spec.ports[0].nodePort}')"

    Then access demodude via browser, using the IP and port shown in the echo commands

Alternative method:
   kubectl port-forward -n {{ .Release.Namespace }} service/{{ .Values.svc.name }} <available-local-port>:{{ .Values.svc.port }}
   
   Then access: localhost:<available-local-port>

{{- else if eq .Values.svc.type "ClusterIP"}}
Access demodude via the following commands:
   kubectl port-forward -n {{ .Release.Namespace }} service/{{ .Values.svc.name }} <available-local-port>:{{ .Values.svc.port }}
   
   Then access: localhost:<available-local-port>
{{-  end }}
